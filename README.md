# Gemini Agent to parse STFC Epubs and extract ISIS experiment numbers

Written as part of the Google/PA/STFC hackathon.

Code was generated by Gemini-3.8-Flash in VSCode/Antigravity.

---

## Agent Skills Architecture

The repository's agent tools have been refactored into modular **Agent Skills** following the [agentskills.io](https://agentskills.io/specification) standard. This provides dual compatibility with:
- **Antigravity Customization System** (located in `.agents/skills/` for pair programming in VS Code / Antigravity).
- **Google Agent Development Kit (ADK)** (`google.adk.skills` and `SkillToolset` in `tool_src/skills.py`).

### Skills Overview

1. **`stfc-epubs-discovery`** ([`skills/stfc-epubs-discovery`](file:///d:/src/gcphack26/skills/stfc-epubs-discovery/SKILL.md))
   - Search the STFC ePubs repository for scientific papers, facility outputs, and reports.
   - Filter by facility (`ISIS`, `Diamond Light Source`, `RAL`) and publication year.
   - Extract and canonicalize publication DOIs (`10.xxxx/...`).
   - Bulk export datasets to CSV or RIS format.
   - **CLI Scripts**: `scripts/search_epubs.py`, `scripts/download_dataset.py`.
   - **References**: `references/facilities.md`, `references/search_guide.md`.

2. **`rb-experiment-extractor`** ([`skills/rb-experiment-extractor`](file:///d:/src/gcphack26/skills/rb-experiment-extractor/SKILL.md))
   - Extract and audit UK facility beamtime allocation experiment numbers (`RB#######`, e.g. `RB1910243`).
   - Deep DOI resolution via CrossRef, Europe PMC, and OpenAlex.
   - Page-by-page PDF scanning of manuscripts and technical reports.
   - Categorize exact beamtime allocations vs general mentions.
   - **CLI Scripts**: `scripts/extract_rb.py`.
   - **References**: `references/rb_patterns.md`, `references/supported_sources.md`.

### Usage in Python (Google ADK)

```python
from tool_src import (
    load_all_stfc_skills,
    create_stfc_skill_toolset,
    create_stfc_research_agent,
    create_stfc_multi_agent_system,
)

# 1. Inspect loaded skills
skills = load_all_stfc_skills()
print([s.name for s in skills])  # ['rb-experiment-extractor', 'stfc-epubs-discovery']

# 2. Create Skill-enabled Google ADK Agent
agent = create_stfc_research_agent(use_skills=True)

# 3. Create Hierarchical Multi-Agent System with specialized skills
multi_agent = create_stfc_multi_agent_system(use_skills=True)
```
